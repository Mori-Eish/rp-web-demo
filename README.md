# RP / PH Web Demo

Reversed Phi (RP) を用いた Pseudo-Haptics (PH) のブラウザデモです。RPは、輝度変化から方向性のある運動知覚を生じさせる錯視です。物理的な力を発生させるものではありません。

**公開サイト:** https://Mori-Eish.github.io/rp-web-demo/

## デモ

- **RPの動きを見る**: 位置を固定した四角形の見かけの進行方向を、上下左右の矢印で切り替えます。周波数・刺激サイズ・エッジ幅を調整できます。
- **ファンの風を受ける**: 四角いカーソルが一定速度で左右に自動往復します。ファンの前では上下方向のRP刺激を提示し、領域外では一様に点滅します。風のイラストは静止しています。初期値は2 Hz・60 px・エッジ幅2.5%です。
- **同方向・逆方向のRP**: カーソルを左右に動かし、4つのエリアで移動方向に対して同方向・逆方向のRPを交互に提示します。
- **しなって見える棒**: 縦に28個並べた刺激にマウスを近づけ、高さごとの距離に応じて左右エッジの表示値を変えます。形と位置は固定し、見かけの変化を観察します。

ヘッダーまたはデモ画面の「English / 日本語」で表示言語を切り替えられます。切替時も設定値・選択方向・再生状態を維持し、言語の選択だけをブラウザ内に保存します。保存できない環境でも、ページ内の切り替えは利用できます。

デモはウィンドウを開くと自動で再生します。タブ非表示やウィンドウのフォーカス喪失で自動停止します。各スライダーの初期値ボタンと、全体のリセットを利用できます。

これは体験用の試作です。風力感などの主観的な感覚の成立や強さを検証済みとするものではありません。研究用刺激の物理寸法・実測輝度・表示タイミングを厳密に再現するものでもありません。

## ローカルで起動

ローカルのデモ一覧には、マウス・タッチ・キーボード入力を確認する「インタラクション・サンドボックス」も表示されます。

Node.js 22以上を推奨します。依存パッケージのインストールやビルドは不要です。

```sh
git clone https://github.com/Mori-Eish/rp-web-demo.git
cd rp-web-demo
npm start
```

ブラウザで http://127.0.0.1:4173/ を開きます。終了はターミナルで `Ctrl+C`。別のポートを使う場合は環境変数 `RP_DEMO_PORT` を設定してください。

```sh
npm test
```

テストは、このリポジトリ内のファイルだけで実行できます。

## GitHub Pagesへの公開・更新

GitHub Pagesは、専用の `gh-pages` ブランチのルートから配信します。このブランチには `dist/` の内容だけを配置します。GitHub側の Settings → Pages → Build and deployment は **Deploy from a branch / gh-pages / (root)** を使用します。

更新はこの専用リポジトリで行い、変更をcommitして `main` にpushした後、次を実行してください。

```sh
npm run deploy
```

テストが成功すると、commit済みの `dist/` を `gh-pages` にpushします。GitHub Pagesが公開サイトを更新します。未commitの変更は公開されません。`main` へのpushだけでは公開内容は更新されません。

研究資料・実験データ・研究リポジトリのGit履歴は、このリポジトリに含めていません。

## ファイル構成

```text
dist/                  公開するHTML・CSS・JavaScript・SVG
  demos/registry.js    一覧へのデモ登録
  demos/_template.js   新しいデモのテンプレート
serve.mjs              ローカル用静的サーバー
tests/                 描画・刺激系列・入力処理のテスト
```

新しいデモは `dist/demos/_template.js` を複製し、`dist/demos/registry.js` の配列へ追加します。英語の説明と設定名は `dist/i18n.js` に追加します。デモ固有の動的な文字列は `t()` で翻訳し、必要ならインスタンスの `localize()` で表示を更新してください。

## しなって見える棒の制御

URLの `#demo/bending-bar` から直接開けます。Unity版の `RP_Bar` と `MouseHoverBarController` の距離計算、および `Smooth4st` のエッジ補間をCanvas 2Dへ移植しています。Unityのシーンやプロジェクト自体は含めていません。

初期値は、各要素が参照するマテリアルの周波数2 Hz、シーン内で有効な28要素、コントローラーの反応距離300 px・最大エッジ幅6%・基底エッジ幅6%・反転モードONに合わせています。棒は表示領域に収まる長さに拡縮し、正方形を隙間なく縦に並べます。物理寸法・Unityのカメラ・色空間の厳密な再現は行っていません。距離はCSS px単位です。

各要素の中心から入力位置までの二次元ユークリッド距離を `d` とすると、近接率は `p = clamp(1 - d / maxDistance, 0, 1)` です。反転モードでは `edgeRatio = max(baseBarHeight, p * maxBarHeight)`、`invertAmount = 1 - p` を使います。左右をL/Rとすると、エッジの表示値はそれぞれ `lerp(L, R, invertAmount)` と `lerp(R, L, invertAmount)` です。単純な白黒反転（1−輝度）ではありません。基準回転−90°と、対象が左にあるときの180°回転も、両端の配置に反映します。

初期値では最大幅と基底幅が同じなので、エッジの幅は距離によらず6%です。距離によって変わるのは両端を交換する量です。反転モードをOFFにすると反転量は0となり、近い部分だけエッジ幅が増え、反応距離の外では中央と同じ一様な点滅になります。UIのエッジ幅は最大幅と基底幅を同時に変更します。

全要素の点滅位相は同期し、周波数変更時も位相を維持します。マウスはクリック不要、タッチはドラッグ、矢印キーは8 px、Shift併用で24 pxの移動です。棒の中心線や輪郭座標を実際に曲げる処理はありません。見かけの曲がり方や感じ方の成立・強さは、観察・検証する対象です。

## 同方向・逆方向のRP

`#demo/alternating-directions` から直接開けます。左から同方向・逆方向・同方向・逆方向の4区間を配置します。区間は、四角形が画面からはみ出さない範囲でカーソル中心が移動できる横幅を4等分したものです。中心が境界上にある場合は右側の区間として扱い、右端は第4区間です。

マウスの横位置にカーソルが追従し、上下位置は中央に固定します。画面端で制限した後のカーソルの実際の横移動から進行方向を求め、同方向区間ではそのまま、逆方向区間では左右を反転したRPを提示します。引き返した際も同じ位置の区間条件を保ち、提示するRPの方向を更新します。上下だけの入力や位置が変わらない入力では方向を変えません。開始時の基準は右向きで、停止中は直前の向きとRP提示を維持します。

初期値はファンのデモと同じ2 Hz・60 CSS px・エッジ幅2.5%です。周波数は0.1–4 Hz、サイズは24–80 px、エッジ幅は0.5–20%で調整できます。エリアをまたぐとき、移動を反転するとき、設定や表示言語を変更するときも点滅位相を初期化しません。背景は固定の灰色です。手動モードでは入力に対する位置ずれを加えません。

境界線と条件名は初期状態で非表示です。「ガイドを表示」をONにすると、静止した3本の境界線と条件名をまとめて表示できます。進入時のエリアの強調や風のイラストはありません。タッチ・ペンはドラッグ、左右の矢印キーは8 px、Shift併用では24 pxで操作します。再生中に言語を切り替えても、位置・方向・区間・設定は維持します。

「自動で往復する」をONにして開始すると、同じ4区間を一定速度で左右に往復します。手動操作と自動往復を切り替えられ、初期状態は自動往復ONです。自動移動の速度は20–300 CSS px/s、初期値50 px/sで調整できます。端では待ち時間なしで折り返し、RPの向きは折り返した後の移動方向と各区間の条件から決定します。

自動モードではマウス・タッチ・矢印キーによる位置変更を無効にします。一時停止中は移動もRPの点滅も停止し、再開時は現在の位置と位相から続けます。モード・速度・表示言語を変えても位置や位相を初期化しません。リセットは左端・自動往復ON・速度50 px/s・ガイド非表示・初期設定へ戻ります。移動は既存プレイヤーの再生中の経過時間に基づくため、非表示タブやフォーカス喪失で自動停止します。

## ファンの自動往復

ファンのデモも自動往復ON・速度50 CSS px/sが初期状態です。再生すると中央の水平経路を一定速度で往復し、風の各エリアで従来と同じ上下方向のRPを提示します。引き返しても風の向きは変えません。領域外の一様な点滅、固定背景、静止した風のイラストも維持します。

自動往復の速度は20–300 px/sで調整できます。自動モードでは手動入力を無効にし、OFFにするとマウス・タッチ・矢印キーによる従来の上下左右の操作を使用できます。再びONにすると横位置と位相を維持し、高さを中央へ戻します。一時停止・再開・リセットは同方向／逆方向デモと同じ共通プレイヤーに従います。

ファンと同方向／逆方向の両デモからSTART／GOALの文字を削除し、ファンのゴール位置を示す円も削除しています。両方の自動往復は同じ移動計算を使用します。
